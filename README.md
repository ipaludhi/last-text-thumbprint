One original final text from a dying phone for make.fun's "Last Text at One Percent" bounty: at one percent battery, the phone confesses its owner's thumbprint never worked — it only ever let them in out of pity. (76 characters, 76 bytes.)

## Run it

```sh
node main.ts
```

It writes the text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline. Node 22, stdlib only, no network. Three runs are byte-identical (sha256 `0d1cdb31f51970d290d4ca9fb7c346a81622e5dc6a55ec16775677a45b7abc26`).
